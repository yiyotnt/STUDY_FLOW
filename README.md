Trabajo grupal de IHC y Tecnologías Móviles — StudyFlow

StudyFlow es una propuesta de plataforma digital de Nexora Solutions que ayuda a los estudiantes universitarios a organizar sus cursos, horarios, tareas y evaluaciones en un solo lugar. El proyecto surge de las dificultades para distribuir el tiempo de estudio, priorizar entregas y llevar un control de las actividades pendientes.

La plataforma también está dirigida a tutores académicos, quienes pueden consultar el progreso de los estudiantes a su cargo, identificar actividades vencidas y dar seguimiento a los acuerdos de tutoría.

Segmentos objetivo

- Estudiantes universitarios que necesitan planificar su tiempo de estudio, priorizar sus entregas y consultar su avance durante el ciclo académico.
- Tutores académicos que acompañan a estudiantes, revisan su progreso e identifican quiénes necesitan apoyo.

Principales características

- Organización de cursos, horarios y sesiones de estudio.
- Registro de tareas y evaluaciones por curso, con fecha límite, prioridad y estado.
- Panel académico personalizable con un resumen diario de actividades.
- Organización de archivos y enlaces de estudio por curso.
- Solicitud de sesiones de tutoría según la disponibilidad del tutor y consulta de los acuerdos establecidos.
- Consulta de actividades vencidas y reportes de progreso para identificar estudiantes que requieren seguimiento.

Tecnologías utilizadas

- Visual Studio Code para editar el código del proyecto.
- HTML, CSS y JavaScript para construir las páginas web e incorporar interacciones.
- Figma para diseñar y prototipar las interfaces web y móviles.
- GitHub para el control de versiones y la colaboración del equipo.
